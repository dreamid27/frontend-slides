Install in 30 seconds

In Claude Code, run these as two separate messages:

/plugin marketplace add https://github.com/dreamid27/frontend-slides
/plugin install frontend-slides@frontend-slides

Using another coding agent (Codex, Gemini CLI, OpenCode…)? Just point it at the repo and ask it to use the Frontend Slides skill. Full instructions →
